# Potsblitz Web

A small web app to train dyslexic people in reading faster. 

## Features

- Word view which displays a single word and allows navigation through a list of words
- Load lists with words from disk
- Various settings to increase or reduce the difficulty

## Usage

- Open `index.html` in a browser to run the app.
- Wordlist files need to be encoded as UTF-8. Use a new line for each word. It is possible to add a hyphen to a word to show how it can be split in indidual chunks. By default, the app will not show the hyphen. This can be switched on/off in the settings.
